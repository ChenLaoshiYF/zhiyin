# 研究总结：同类项目架构与 UI 设计（2026-08-12）

> 为改进俄汉同传桌面工具而做的调研，结论已落地到代码。

## 一、同类开源项目

| 项目 | 链接 | 借鉴点 |
|---|---|---|
| WhisperLive (collabora) | github.com/collabora/WhisperLive | 服务端独立翻译线程；Windows 环境变量（KMP_DUPLICATE_LIB_OK / OMP_NUM_THREADS）；hotwords 术语 |

## 二、代码结构最佳实践（已落地）

- **流水线编排独立成模块**（pipeline.py）：采集 → ASR → 翻译三段独立线程 + 队列解耦；UI 线程零推理，只消费渲染队列
- **翻译接口可插拔**（translator.py）：BaseTranslator 抽象，Cloud（Ollama/OpenAI 兼容）/ Local（NLLB）可切换可降级
- **配置集中**（config.json）：模型、后端、术语表、文稿、UI 全集中管理
- **Windows 环境变量**：main.py 启动时设置 KMP_DUPLICATE_LIB_OK、OMP_NUM_THREADS（WhisperLive 经验）

## 三、翻译过程优化（已落地）

1. **流式翻译**：Ollama /api/chat stream:true 逐 token 推送，字幕边生成边更新，感知延迟大幅下降
2. **俄文先显、中文后补**：识别结果立即显示俄语，中文翻译增量补充，不再等整句翻完
3. **术语表注入**：config.json 的 glossary 注入 system prompt，专名术语识别稳定（实测：закон Ома→欧姆定律、сопротивление→电阻）
4. **译文上下文**：最近 2 句译文拼进 prompt，保持术语与风格一致
5. **强制语言 ru**：跳过语言检测省一次前向开销

## 四、UI 设计原则（已落地）

参考 YouTube Live Captions / Windows Live Captions / OBS 字幕 / Immersive Translate：

1. **最小遮挡**：字幕窗 3 行以内，底部居中，点击穿透
2. **对比度至上**：黑底 rgba(0,0,0,150)（约 55% 透明度）+ 白字，满足 WCAG 4.5:1
3. **双行层级**：中文主行大号白字（用户读的），俄文副行小号弱化（对照参考）
4. **细节**：12px 圆角、20px 阴影、内边距 20/12、行距 6px、Segoe UI（西里尔字母渲染好）+ 微软雅黑
5. **控制条**：紧凑横条、自动隐藏（2.5s 淡出）、颜色状态（暂停高亮）、拖拽整体移动（字幕窗跟随）、复位按钮
